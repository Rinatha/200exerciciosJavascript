200 Exercícios de JavaScript — Lote 81 a 100
------------------------------------------------
Como usar:
- Execute cada arquivo individualmente com Node.js:
  node exercicio81.js
  node exercicio82.js
  ...
  node exercicio100.js

Observação:
- Cada arquivo contém o enunciado em comentário, a solução e exemplos rápidos de teste.
- Fique à vontade para ajustar os exemplos (arrays, strings, valores) para novos testes.
